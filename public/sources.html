Source and licenses

Browser Linux is an experimental workstation built on Joel Severin’s Linux/Wasm port. The Linux kernel, musl and BusyBox run locally in your browser. The desktop and its filesystem bridge are open source.

  • Application source, build scripts and pinned patches
  • Download upstream source bundle (includes Linux, BusyBox, musl, LLVM, patches, configurations and notices)
  • Source manifest and verification details
  • GNU General Public License, version 2
  • xterm.js license and fit addon license

New application code and the upstream runtime are GPL-2.0-only. Each upstream component keeps its own license. The bundle contains the source releases and patches used by the archived build recipe; the kernel build was not reproduced byte-for-byte here. The patch chain’s final kernel revision matches the running binary’s version identifier.

The kernel port remains experimental, with known intermittent boot and file-integrity failures. See the repository for limitations, recovery checks and test results.
