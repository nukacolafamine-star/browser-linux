Workspace & recovery

Your /home/web files are saved in this browser every 10 seconds and when you save a file. Other Linux folders reset on reboot.

Export a backup to move your work or protect it from browser data removal. Running processes are not saved.

An early Linux/Wasm workstation

The kernel and BusyBox commands run as WebAssembly on your device. Files and the editor use real Linux system calls through a dedicated guest process. The desktop interface is built for the browser.

This build has no Linux networking, conventional package repository, or accelerated Linux graphics yet. The upstream kernel port is experimental. It does not modify or replace your host operating system.
